  Call Centre Performance Analysis Dashboard

This Power BI dashboard visualizes key metrics from a call centre, helping to track agent performance, call volume trends, and customer wait times.

 Tools Used
- Power BI
- Excel (data preparation)

 Features
- Total calls per day/week/month
- Agent response time and performance metrics
- Customer satisfaction overview
- Drill-down by agent and department

Key Insights
- Call volumes peak during the first half of the week.
- Average wait times decreased by 15% after a schedule adjustment.
- One agent consistently had the highest call resolution rate.

 Files Included
- `Call_Centre_Analysis.pbix` – Power BI file
- `Call_Data.xlsx` – Raw dataset (optional)
